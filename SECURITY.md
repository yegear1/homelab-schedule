# Security Policy

## Supported Versions

Security updates and patches are actively provided for the following releases:

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| < 0.4.0 | :x:                |

---

## Reporting a Vulnerability

The maintainers of **homelab-schedule** take security seriously. If you discover a vulnerability or potential security risk, please report it privately:

1. **GitHub Security Advisory (Preferred):**
   Open a private advisory via the [Security Advisories tab](https://github.com/yegear1/homelab-schedule/security/advisories).
2. **Direct Contact:**
   If you cannot submit via GitHub, email maintainers at [yegear1@users.noreply.github.com](mailto:yegear1@users.noreply.github.com).

### Information to Include

Please provide:
- A description of the issue and potential impact.
- Step-by-step reproduction instructions or a minimal proof-of-concept (PoC).
- Any proposed remediations or patches if available.

### Response SLA

- **Acknowledgment:** Within 48 hours of initial report.
- **Triage & Status:** Maintainers will investigate and provide status updates as triage progresses.
- **Resolution:** Critical security fixes will be published in a patch release and documented in `CHANGELOG.md`.

Please do not open public GitHub issues or disclose vulnerabilities publicly before maintainers have investigated and addressed the report.
